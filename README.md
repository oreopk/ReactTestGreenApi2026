# Чат MAX — тестовое задание

Приложение на React для отправки и получения текстовых сообщений в MAX через GREEN-API.

Стек: React, Vite, react-imask, nanoid.

## Локальный запуск

Понадобятся Node.js 24 и npm.

1. Скачайте репозиторий

2. Установите зависимости:

   npm install

3. Запустите приложение:

   npm run dev

## Подготовка GREEN-API

В [личном кабинете GREEN-API](https://console.green-api.com/) создайте инстанс MAX и привяжите аккаунт.

Для получения сообщений включите уведомления о входящих сообщениях (`incomingWebhook: yes`), а адрес отправки уведомлений (`webhookUrl`) оставьте пустым.

## Использование

1. Введите `idInstance` и `apiTokenInstance` из личного кабинета.
2. Введите номер получателя и создайте чат.
3. Отправьте текстовое сообщение.
4. Ответьте с аккаунта получателя в MAX — ответ появится в открытом чате.

Загрузка истории нет, после обновления страницы переписка в интерфейсе очищается.
